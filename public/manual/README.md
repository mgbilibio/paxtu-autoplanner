# Capturas do manual (ScoutsAuto)

Coloque aqui as PNG reais do site ao vivo. O HTML (`docs/usersmanual.html`) e a prévia in-app procuram:

| Arquivo | Tela |
| --- | --- |
| `login.png` | Login |
| `efetivo.png` | Efetivo (filtre/recorte nomes de jovens) |
| `estrutura.png` | Estrutura |
| `gerar.png` | Gerar roteiro / cronograma |
| `agenda.png` | Agenda |
| `relatorios.png` | Relatórios |
| `acessos.png` | Log de acessos |

Sem arquivo, o manual mostra o retângulo de reserva. Não use imagens geradas da interface.
