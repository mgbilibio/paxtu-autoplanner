# Capturas do manual (ScoutsAuto)

PNG reais do site ao vivo. O HTML (`docs/usersmanual.html`) e a prévia in-app procuram estes arquivos em `manual/<nome>.png` (o site publica `public/manual/`).

| Arquivo | Tela |
| --- | --- |
| `login.png` | Login (Google ou e-mail e senha) |
| `inicio.png` | Início / Bem-vindo ao ScoutsAuto |
| `efetivo.png` | Efetivo — filtros e “Adicionar novos membros” (chrome recortado, sem nomes de jovens) |
| `estrutura.png` | Estrutura — cabeçalho do grupo e cartão da seção (chrome recortado, sem nomes de jovens) |
| `gerar.png` | Gerar — seletor de ramo (não é a tabela do cronograma) |
| `agenda.png` | Agenda / Calendário Global |
| `relatorios.png` | Relatórios — só cartões de resumo (chrome recortado, sem nomes de jovens) |
| `acessos.png` | Log de acessos (contas adultas) |

`efetivo.png`, `estrutura.png` e `relatorios.png` são recortes de chrome de propósito: nenhum nome completo de jovem nem registro UEB.

Não use imagens geradas da interface.
