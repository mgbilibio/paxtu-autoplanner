PDFs Normativos para Instalador NSIS
====================================

Esta pasta contem PDFs que serao empacotados no instalador do PaxTuPlanner.

Coloque aqui os seguintes arquivos (se possuir):
- 2025.10.Manual do Escotista - Lobinho.pdf
- 2025.10.Manual do Escotista - Escoteiro.pdf
- Guia de Especialidades 18a Edicao - 2024-1.pdf

Todos os PDFs nesta pasta serao automaticamente incluidos no instalador NSIS
e acessiveis via "Abrir Manual" no aplicativo.

Nota: O aplicativo buscara os PDFs primeiro no instalador, depois em docs/biblioteca/.
