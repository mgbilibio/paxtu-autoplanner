# ANEXO TÉCNICO

# BONECO DE PANO

## Materiais:
- um pedaço quadrado de pano de uma cor
- agulha
- algodão
- caneta para pintar tecido
- tesouras
- giz para tecido
- fio

## Instruções

1. Desenhar sobre o pedaço de tecido as linhas pontilhadas que representam as diferentes partes do boneco, conforme a figura 1. Fazer dois pequenos cortes conforme se indica na mesma figura.

2. Com umas voltas de fio, formar o topete (fig.2)

3. Modelar uma bola de algodão para formar a cabeça. Coloca-la no tecido embaixo do topete e, com umas voltas de fio, formar a cabeça fechando o pescoço. (fig. 3).

4. Passar as pontas que correspondem os braços pelos buracos do tecido de trás para frente (fig. 4).

5. Modelar uma bola maior para formar o corpo. Coloca-la no tecido. Costurar a parte de trás com alguns pontos (fig. 5).

6. Levantar o peitilho e costurá-lo na parte da frente (fig. 6).

7. Dar umas voltas de fio nas pernas e braços (fig. 7). Pintar o rosto do boneco.
