# Confeitaria

☐ 1. Preparar 1 (um) bolo, uma torta e uma sobremesa típica da sua região e/ou cultura para a seção.
☐ 2. Preparar docinhos caramelados ou glaçados, ou bombons recheados.
☐ 3. Preparar 1 (um) bolo artisticamente confeitado, com modelo copiado de uma publicação, que deve ser exibida para comparação.
☐ 4. Preparar salgadinhos, arrumando-os em uma bandeja para servir aos convidados a uma festa.
☐ 5. Identificar os ingredientes necessários para fazer 1 (um) bolo para cinquenta pessoas, calculando seu custo.
☐ 6. Preparar 1 (um) doce a partir de uma receita fornecida pelo examinador.
☐ 7. Preparar, em 1 (um) acampamento, 3 (três) doces ou sobremesas.
☐ 8. Preparar 1 (um) doce light ou diet.
