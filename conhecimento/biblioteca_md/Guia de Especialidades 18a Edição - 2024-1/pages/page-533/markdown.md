# Reparos Domésticos

☐ 1. Demonstrar que conhece as regras de segurança para a execução de um reparo elétrico.
☐ 2. Realizar um reparo elétrico descrevendo o serviço executado.
☐ 3. Realizar a troca de uma torneira ou a troca de uma gaxeta.
☐ 4. Realizar a regulagem de uma descarga.
☐ 5. Realizar o reparo de gesso em uma pequena área de uma parede.
☐ 6. Realizar a preparação de uma parede para pintura.
☐ 7. Montar uma caixa com as ferramentas básicas para reparos domésticos.
☐ 8. Demonstrar que sabe utilizar as ferramentas com precisão e segurança.
☐ 9. Realizar o conserto de um brinquedo (troca de rodinhas, montagem de um boneco, costura de uma pelúcia etc.).
☐ 10. Realizar o reparo de um móvel, realizando a troca de, pelo menos, uma ferragem (corrediças, dobradiças, fechaduras etc.).
