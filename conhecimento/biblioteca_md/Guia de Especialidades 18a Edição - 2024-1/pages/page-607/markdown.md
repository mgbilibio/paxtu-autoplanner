# Técnicas de Sapa

1. Limpar o terreno para a montagem do local onde ficará o material de sapa.
2. Fazer uma fossa para líquidos.
3. Demonstrar os cuidados a adotar no manuseio de ferramentas de sapa.
4. Montar uma latrina de campo.
5. Utilizar a serra traçante ou qualquer outro tipo de serra que precise ser manuseada por mais de uma pessoa.
6. Afiar ferramentas de sapa.
7. Enumerar e identificar as ferramentas de sapa.
8. Demonstrar os cuidados para a conservação em bom estado das ferramentas de sapa.
9. Recuperar ferramentas de sapa danificadas.
